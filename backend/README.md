# Stars Homes ERP - Backend Layer

هذا المجلد يمثل طبقة الخادم والبيانات السحابية (Backend Layer) لمشروع Stars Homes:

## المحتويات:
1. **`database/`**:
   - `00_master_schema_init.sql`: المخطط العام لقاعدة البيانات السحابية (Supabase PostgreSQL).
   - `migrations/`: ملفات التحديثات وتعديل الجداول والصلاحيات (RLS Policies).
2. **`docs/`**:
   - توثيق شامل لبنية الجداول والربط والتفويض السحابي.
