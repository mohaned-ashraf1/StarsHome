# دليل الأمان وحماية البيانات (Security & Data Protection)
## STARS HOMES ERP — Enterprise Security Standard

تم تصميم تطبيق **STARS HOMES ERP** ليعمل كمنظومة إدارية مؤسسية محكمة تحمي أسرار المصنع ومعاملاته المالية وقاعدة بيانات العملاء.

---

### 1. تخزين الاعتمادات والرموز السرية (Zero Hardcoded Secrets)

1. **الرموز السرية ومفاتيح الربط**:
   - لا توجد أي كلمات مرور أو مفاتيح سرية مكتوبة بشكل نصي داخل الكود (No Hardcoded Secrets).
   - يتم تحميل عناوين الاتصال من ملف البيئة `.env`.
2. **التخزين المشفر للمفاتيح (Encrypted Storage)**:
   - على أجهزة الكمبيوتر **Windows 11**: يتم التشفير عبر نظام **Microsoft DPAPI** (Data Protection API) المرتبط بحساب المستخدم ونظام التشغيل.
   - على أجهزة **Android**: يتم التشفير عبر شريحة الأمان ومستودع المفاتيح **Android Keystore** و **EncryptedSharedPreferences**.
3. **حماية رمز الدخول (PIN Code)**:
   - يتم تخزين تجزئة مشفرة (Hash) لرمز الدخول، ويشترط إدخال الرمز القديم للتحقق قبل قبول أي رمز جديد.

---

### 2. سياسات حماية قاعدة البيانات (Row Level Security - RLS)

- تم تفعيل سياسات **RLS** على كافة جداول Supabase في السحابة.
- تمنع السياسات أي طلبات خارجية غير مصرح بها من الوصول إلى البيانات.
- جدول سجل الأنشطة `audit_logs`: مبرمج بسياسة **Append-Only** (إضافة فقط) تمنع التعديل أو الحذف لأي سجل لضمان عدم تزييف أي نشاط رقابي.

---

### 3. سلامة البيانات ومزامنة الحذف المزدوجة (Two-Way Sync & Soft Delete)

- **مزامنة الحذف التلقائي**:
  - عند حذف طلبية أو دفعة أو سجل من أي جهاز (سواء من هاتف المندوب أو كمبيوتر الإدارة)، يتم تسجيل أمر الحذف في طابور المزامنة `sync_queue`.
  - فور الاتصال بالإنترنت، يُنفذ الحذف على السيرفر السحابي Supabase وتنعكس النتيجة فوراً على كافة الأجهزة الأخرى المعتمدة، مما يمنع ظهور البيانات المحذوفة مجدداً.
- **تصفير البيانات التجريبية بأمان**:
  - يحتوي ملف `backend/database/reset_factory_data_clean.sql` على أوامر تنظيف متسلسلة تحذف بيانات الاختبار والطلبيات القديمة دون المساس بحسابات المستخدمين أو هيكل الجداول.
